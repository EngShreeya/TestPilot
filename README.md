
# TestPilot 🚀

AI-Powered Autonomous Website Testing Platform.

## Overview

TestPilot helps developers automate website testing,
identify bugs, and understand test failures using AI.

## Tech Stack

- React + Vite
- Node.js + Express
- MongoDB
- Playwright
- Gemini API
- Tailwind CSS

## Features

- AI Test Case Generation
- Automated Browser Testing
- Natural Language Testing
- AI Bug Explanation
- Visual Bug Detection
- Test Reports and History

## Project Structure

- client/ - Frontend
- server/ - Backend
- worker/ - Browser automation
- docs/ - Documentation

## Project Status

Currently under development.
